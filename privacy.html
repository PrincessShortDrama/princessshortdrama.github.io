Summary

The PrincessShortDrama Uploader is a private desktop tool used only by the owner of the PrincessShortDrama YouTube channel to upload that channel's own videos. It does not collect, sell or share anyone's personal information.

YouTube API Services

The tool uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy, and use of YouTube is governed by the YouTube Terms of Service.

What the tool accesses

With the channel owner's permission (Google sign-in), the tool uses the YouTube Data API to upload videos, thumbnails and subtitle files to the owner's channel, set video details and publishing times, and add videos to the owner's playlists. It reads only what it needs to do this, such as the channel's playlists and the status of its own uploads.

What is stored, and where

The sign-in token that lets the tool upload is stored only on the channel owner's own computer. The tool keeps a local record of which episodes it has uploaded. Nothing is stored on any server run by the tool, and no data is sent to anyone other than Google/YouTube.

Sharing

No data is shared with, sold to or used by any third party. No analytics, advertising or tracking is used.

Removing access

Access can be removed at any time from the Google account's third-party access settings.

Data deletion

The only data the tool keeps is the sign-in token and a list of the episodes it has uploaded, both stored on the channel owner's own computer. When access is revoked, the token stops working and is deleted the next time the tool runs. All stored data can be deleted at any time by deleting the tool's folder, and any stored YouTube API data is deleted within 30 days of a request or of access being revoked. Videos already uploaded remain on the YouTube channel and can be deleted in YouTube Studio.
